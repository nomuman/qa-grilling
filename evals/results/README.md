# Release-candidate results

Store one immutable, privacy-safe evaluation record per release candidate.

Each record must identify the candidate, date, supported hosts and versions, model, review mode, verification class, activated domain packs, pass/partial/fail evidence, blockers, and final release decision. Static instruction review, live-host behavior, CI, and published-release verification remain separate rows.

Do not include prompts or outputs containing secrets, private reviewed content, local account identifiers, or personal filesystem paths.
