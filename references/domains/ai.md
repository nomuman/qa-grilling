# AI and LLMs

Activate for model-generated content, retrieval, tools, or autonomous actions.

Consider nondeterminism, hallucination, prompt injection through user or retrieved content, unsafe tool execution, provider timeout, materially different retry output, partial streaming, stale retrieval, citation mismatch, sensitive prompts or logs, provider data handling, model changes, fallback behavior, confidence, and user understanding of suggestion versus committed action.

Separate generation from authorization and commit whenever an AI result can cause a side effect.
