# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through this repository's GitHub Security Advisories rather than opening a public issue.

Include the affected version, the trust boundary involved, the observed behavior, and a minimal safe reproduction. Do not include secrets, private reviewed content, or destructive proof-of-concept steps.

## Scope

Security-relevant behavior includes prompt injection through reviewed artifacts, unintended tool or side-effect authorization, sensitive data disclosure, invocation-policy bypass, and release-integrity problems.
